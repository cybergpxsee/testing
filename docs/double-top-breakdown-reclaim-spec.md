# 美股雙頂 → 破底翻 → 回調買點規則說明

這份文件主要記錄目前 repo 內建的做多日線核心邏輯；另外 long / short 兩邊都保留一條對稱 fallback：

- 做多 fallback：**雙頂後先走出一段急跌，再回踩主升段 0.5-0.618 後重新轉強**，標記為 `雙頂→右側回調買點`
- 做空 fallback：**雙底後未重返舊頸線、但回抽大跌段 0.5-0.618 後快速轉弱**，標記為 `雙底→右肩回調賣點`

## 1. 形態定位

這不是 textbook 頭肩底偵測器。

這版掃描器的交易流程是：

1. 先找 **明顯雙頂**
2. 再找雙頂後的 **跌破支撐 / 破底翻**
3. 再確認 **近期下降趨勢線被打破**
4. 最後只做 **回踩 0.5-0.618 黃金回撤區** 的第二買點

換句話說，綠圈不是直接追買點；真正要做的是紫圈那種回調共振位。

## 2. 雙頂 / 雙底硬條件

- 做多母結構：必須有兩個明顯局部高點
- 做空母結構：必須有兩個明顯局部低點
- 兩頂 / 兩底相隔至少 **20 個交易日**
- 雙頂價格差 **2% 以內**；雙底價格差 **2% 以內**
- 若兩頂 / 兩底相隔 **60 個交易日以上**，作加分項
- **雙頂之間不能出現高過兩個頂的價格**，否則不算雙頂
- **雙底之間不能出現低過兩個底的價格**，否則不算雙底
- **第二個頂之後只要曾跌破雙頂之間谷底，整個雙頂形態直接失效**
- **第二個底之後只要曾升破雙底之間峰頂，整個雙底形態直接失效**

## 3. 結構失效與候選淘汰

- 只要母結構被上面兩條失效規則破壞，後面即使重新拉回 / 跌回，也**不能再沿用原本那組雙頂 / 雙底**
- 做多、做空兩邊都按同一原則處理，不接受「先破壞母結構，再收回去」的補救式判定

## 4. 確認段

- 母結構仍然有效時，不是立刻買
- 需等待價格打破近期下降趨勢線
- 並且自破底翻低點起，至少先走出一段可量測的上升腿

## 5. 回調買點條件

以「破底翻低點 → 確認高點」作為上升腿，計算黃金回撤。

合格買點需符合：

- 回調低點落在 **0.5 ~ 0.618** 區間
- 若跌穿 **0.618**，則需在 **5 個交易日內收回 0.618 上方**
- 回調後必須出現重新轉強 / 轉弱觸發：可用日線突破 / 跌破前一日高低，或同日 **30m 反轉結構** 作確認

## 6. 支撐共振評分

回調位左方越多共振，分數越高。

### 高權重
- 成交密集區 / 籌碼密集區

### 次高權重
- 平台區
- 前高支撐
- 支撐線 / 趨勢線
- 回調到區間時，價格高於 **20 個交易日前收市價**

### 打分原則
- 有籌碼密集區時，加分最高
- 籌碼密集區 + 平台區同時命中，額外加分
- 其他支撐元素可疊加共振分
- 若日線已到回調區，則再檢查 **30 分鐘圖** 是否出現對應反應：
  - 做多：`破底翻後回前高` / `震倉後回前高`
  - 做空：`假突破後回前低` / `上插震倉後回前低`
- 有 30 分鐘觸發者，在榜單上顯示對應狀態，且排序優先

## 7. 止損規則

優先順序：

1. 放在 **籌碼密集區下沿下方**
2. 沒有籌碼密集區時，放在 **平台/前高支撐下方**
3. 若缺乏明確結構，退回 **5% 止損**

## 8. 目標價規則

- **目標1**：雙頂壓力區
- **目標2**：以「破底翻低點 → 確認高點」為主升腿，從回調低點做 **1.618 趨勢延伸**

## 10. 榜單展示規則

- 對外榜單只保留：`代碼 / 回調日 / 買點或賣點 / 30m`
- 不顯示：`止損 / 目標1 / 目標2`
- 榜單排序改為：**先看回調日，再看 30m**；若回調日相同，再由 long / short 對應的 30m 強訊號優先
- 版面順序固定為：**兩個回調買榜在前、兩個回調賣榜在後**

## 11. 設計取向

這版核心思想是：

> 不是抄破底翻第一腳，而是等破底翻後的上升確認，再做有黃金回撤 + 結構支撐共振的第二買點。
